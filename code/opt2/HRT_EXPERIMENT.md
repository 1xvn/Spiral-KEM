# OPT2 HRT 메시지 인코딩 실험

기준 체크아웃은 `cbaf58de6d67178b1262156c7356f9cecb946956`이다. [OPT2](spiral_kem_toy_v031_opt2.py)의 `_encode_message`는 메시지 비트를 바이트별 하위 비트부터 읽어 계수 중심 0과 1664에 놓는다. `_decapsulate_core`는 `v − sᵀu`를 계산한 다음, `_decode_message`에서 나머지 833~2496을 1로 해석한다. 이후 동일 메시지로 재암호화하고 기존 16비트 직렬화로 암호문을 비교해 공유 키를 선택한다.

OPT2의 [SKW1](COMPACT_WIRE_SPEC.md)은 두 계수를 3바이트에 무손실 포장한다. `serialize_ciphertext_compact`와 `deserialize_ciphertext_compact`가 12비트 포장·해제를 담당한다. 기존 16비트 경로에는 같은 계수가 그대로 들어간다. [C KEM](../../native_research/spiral_native.c)도 `pack12` / `unpack12`와 기존 비트 중심을 사용하며, Rust 프로토콜은 [FFI](../../protocol_rust/src/ffi.rs)를 통해 C KEM을 호출한다. 후보의 인코딩·디코딩 오버라이드는 이 Python 실험에만 있다.

## 후보와 보장 범위

`j=0…127`마다 원래 메시지의 비트 `j`를 기호의 하위 비트, `j+128`을 상위 비트로 둔다. 기호 `00, 01, 10, 11`의 중심은 각각 `0, 832, 1664, 2496`으로 정하고 계수쌍 `(j,j+128)`에 `(c,0)`을 넣는다. 관측 계수쌍 `(u,v)`는 `x = (u + 1729·v) mod 3329`로 투영한다. 각 중심의 비용은 다음과 같다.

```text
D(x,c) = min { max(|e_u|, |e_v|) :
               (c + e_u + 1729·e_v) mod 3329 = x }
```

오차의 최대 절댓값을 0부터 늘려 도달 가능한 나머지를 처음 방문할 때의 비용을 기록한다. 가장 낮은 비용의 기호를 고르고, 동점이면 숫자가 작은 기호를 선택한다. 전체 3,329개 나머지 가운데 두 기호의 동점이 **197개**다. 모든 나머지의 판정을 각 가능한 `e_v`와 그에 대응하는 최소 절댓값의 `e_u`를 사용하는 독립 계산으로 확인했다.

각 계수 오차가 `-6…6`이면 기호당 169개씩 총 **676개** 관측값이 모두 다르고 모두 원래 기호로 복호된다. 모든 계수쌍이 이 조건을 충족하면 32바이트 메시지 전체가 복호된다. 범위를 `-7…7`로 넓히면 `00 + (3,-6)`과 `01 + (-3,7)`이 모두 2945가 된다. 해당 나머지를 받으면 최소 비용 규칙이 `00`을 선택한다. 이 충돌 때문에 주어진 투영과 중심으로 반경 7 전체의 정확한 복호를 보장할 수 없다.

## 1,000회 관측

매 회차 공개 SHAKE256 fixture에서 얻은 세 시드로 키쌍을 한 번 생성했다. 동일한 32바이트 메시지로 기존 OPT2와 후보의 `encapsulate`를 각각 호출했다. 두 호출은 같은 공개 키와 메시지에서 `r,e1,e2`의 시드를 파생한다. 회차별로 두 암호문의 `u`와 인코딩을 제외한 복호기 입력 오차가 같은지 확인했다. 각 암호문을 SKW1과 기존 16비트 형식으로 각각 왕복시켜 계수 일치를 확인했다. SKW1 해제 결과로 전체 메시지와 정상 `decapsulate`의 공유 키 결과를 측정했다.

| 항목 | 기존 OPT2 | HRT 후보 |
|---|---:|---:|
| 32바이트 메시지 복호 실패 | 0 / 1,000 | 1,000 / 1,000 |
| 송수신 공유 키 불일치 | 0 / 1,000 | 1,000 / 1,000 |
| SKW1 암호문 크기 | 1,160바이트 | 1,160바이트 |
| 기존 16비트 암호문 크기 | 1,589바이트 | 1,589바이트 |

후보의 관측 최대 계수쌍 오차는 75였다. 이 실험의 실패 횟수는 지정한 공개 fixture에서의 관측치다. 반경 6 보장은 위의 순수한 인코딩·투영·복호 규칙에 대한 것이다. 원본 JSON에는 실행 명령, 소스 해시, 동점 수, 크기별 개수와 오차 히스토그램이 있다. [결과 JSON](evidence/hrt_opt2_1000.json)

## 결합 후보 `--candidate combined`

착수 시 브랜치는 `research/opt2-hrt`, HEAD는 `cbaf58de6d67178b1262156c7356f9cecb946956`였다. 당시 작업 트리에는 수정된 `README.md`와 미추적 `HRT_EXPERIMENT.md`, `experiment_hrt.py`, `test_hrt.py`, `evidence/hrt_opt2_1000.json`이 있었다. 기존 투영 후보의 원본 JSON은 그대로 보존했고, SHA-256은 `bbb7916b0289dc58d92b25077667b23c90a3598dd6bc26999a99b1504f5d4806`이다.

`q=3329`, `n=256`에서 각 `j=0…127`에 대해 OPT2의 비트 `j`를 `a`, 비트 `j+128`을 `b`로 읽는다. 계수 `j`와 `j+128`에 각각 `x=1664a`와 `y=(1664b+800a) mod 3329`를 저장한다. 아래 기호는 `ab` 순서로 적는다.

| 기호 | 계수쌍 `(x,y)` | `(x+1729y) mod 3329` |
|---|---|---:|
| `00` | `(0,0)` | 0 |
| `01` | `(0,1664)` | 800 |
| `10` | `(1664,800)` | 0 |
| `11` | `(1664,2464)` | 800 |

`1729·1664 ≡ 800`이고 `1664+1729·800 ≡ 0`이므로 투영값은 항상 `800b`다. `b`가 HRT 동치류를, `a`가 그 안의 대표를 선택한다.

기존 역캡슐화의 `v − sᵀu`가 만든 계수쌍에서 OPT2 판정으로 먼저 `a`를 읽고, 두 번째 계수에서 `800a`를 빼서 같은 판정으로 `b`를 읽는다. 디코더는 두 비트를 원래 위치에 놓아 32바이트를 복원한다. 계수 판정표는 기존 OPT2 디코더에 3,329개 나머지를 넣어 생성한다.

오차 절댓값이 831 이하이면 중심 0 주위의 나머지는 `0…831` 또는 `2498…3328`이고 중심 1664 주위는 `833…2495`다. 기존 OPT2 판정이 이를 각각 0과 1로 올바르게 읽으므로 먼저 `a`가 복원된다. 그 값으로 `800a`를 빼면 `b`의 중심과 두 번째 계수 오차만 남는다. 실제 계수쌍 디코더로 기호당 `1663² = 2,765,569`가지, 총 **11,062,276가지**를 전수 확인했다. 반경 832에서는 `00+(0,+832)`와 `01+(0,-832)`가 모두 `(0,832)`로 관측돼 어느 결정적 디코더도 이 두 원래 기호를 동시에 복원할 수 없다. 기존 판정은 그 관측을 `00`으로 읽는다.

### 결합 후보 1,000회 관측

기존 실험과 같은 공개 fixture를 사용했다. 회차별로 하나의 키쌍과 동일한 메시지를 두 인코딩에 제공했다. 기존 `encapsulate`가 파생한 난수를 공유한다는 점을 두 암호문의 `u`와 복호 직전 계수 오차가 같은지 대조해 확인했다. 각 암호문을 SKW1과 레거시 형식으로 따로 직렬화하고, 양쪽에서 파싱한 객체 각각에 `decapsulate`를 실행했다. 같은 인코딩의 두 포맷에서 복원된 계수와 공유 키가 일치함을 확인한 뒤 회차별로 한 번 집계했다.

| 항목 | 기존 OPT2 | 결합 후보 |
|---|---:|---:|
| 완료한 비교 | 1,000 | 1,000 |
| 32바이트 메시지 복호 실패 | 0 | 0 |
| 송수신 공유 키 불일치 | 0 | 0 |
| SKW1 암호문 크기 | 1,160바이트 | 1,160바이트 |
| 레거시 암호문 크기 | 1,589바이트 | 1,589바이트 |
| 관측한 최대 계수 오차 절댓값 | 75 | 75 |

각 회차에서 두 인코딩의 암호문은 서로 달랐다. 결합 후보의 128,000개 계수쌍 중 반경 831을 초과한 쌍은 0개였다. 오차는 복호기의 `v − sᵀu`에서 원래 인코딩 계수를 뺀 뒤 `[-1664,1664]`의 대표로 환산해 측정했다. 실패 0건은 이 1,000회에서의 관측이며, 반경 831은 두 계수 모두 해당 범위에 있을 때 성립하는 복호 보장이다. [결합 후보 결과 JSON](evidence/hrt_opt2_combined_1000.json)
